# MEN'S — Figma-inspired men's fashion website

This project uses the supplied image assets and recreates the provided Figma layout with:
- Header and navigation
- Hero section
- Essentials cards
- Autumn Collection banner
- Trending Now products
- Explore Our Products collage
- Social media strip
- Footer

## GitHub Pages structure

Keep these files and folders in the repository root:

- `index.html`
- `style.css`
- `script.js`
- `images/`

Do not rename the `images` folder or the files referenced in `index.html`.
